# Marseloid

Multi-page personal website: Next.js App Router + TypeScript + Framer Motion, Python FastAPI.
Domain: marseloid.online. Public contact: @marseloid.

Research lives in `docs/research`; visual decisions in `docs/DESIGN.md`.

## Checks

```
npm run build
npm run typecheck
npm run test:backend
```

Contact brief stays in the browser and is manually sent by the visitor via Telegram. No leads are silently collected. Python API validates illustrative calculations; prices are not real offers.
Fonts: self-hosted Manrope, see public/fonts/OFL.txt. Cover illustrations are original CSS/SVG, not screenshots of projects.

See `deploy/README.md` for local preview, containers and bot configuration.
