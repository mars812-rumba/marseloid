# Marseloid · visual system

Skills: ui-ux-pro-max (portfolio grid / technical minimalism), framer-motion-core + framer-motion-react.

The database recommendations mixed dark-only style with a light palette. Resolve deliberately as a warm light editorial website with dark demonstration surfaces, not two incomplete themes.

- Warm paper background, near-black typography, muted graphite, restrained burnt-orange action color.
- Manrope, self-hosted Cyrillic/Latin; monospace labels for technical metadata only. Space Mono was suggested but lacks the required Cyrillic coverage.
- Wide asymmetric editorial hero, live illustrative configurator, numbered service rows, large evidence-first project cards.
- One primary action per section. No fabricated metrics, logos, headshots or testimonials.
- Spacing: 4/8 px scale, 24 px mobile gutter, 64 px desktop gutter, 1280 px maximum content width.
- Controls at least 44 px, visible keyboard focus, persistent labels, contrast-tested semantic tokens.
- Motion: Framer Motion entrances on hero text, section headings, service rows, project cards, process steps and article sections. One-time 36 px rise + opacity 0.15→1, 650 ms, with 70–120 ms stagger for related items. Hover/press feedback uses a small spring scale. Demo state changes remain 180–250 ms. MotionConfig reducedMotion=user; reduced-motion users get immediate content without entrance or gesture transforms. Server HTML stays visible, with no content waiting hidden for scroll or JavaScript. Continuous motion is reserved for the explicitly requested floating device mockups: pause offscreen, in hidden tabs, during gestures and for reduced motion; provide a pause control. Preserve the orange accent and existing composition when adjusting motion.
- Responsive check: 375, 768, 1440 px; keyboard, reduced motion, enlarged text and landscape.
- Case evidence: Chimneys uses reviewed real desktop/mobile captures in the project cover and a six-step gallery. Transparent presentation surface with a device switch: a floating laptop for desktop captures and the existing phone for mobile captures. Only the selected mockup is mounted, keeping the active screenshot when switching. Both devices have separate zoom controls in the native modal. Sunny keeps its labeled illustration and in-development status. Only optimized, reviewed assets in public/cases are published; raw screenshots stay out of Git and Docker build context.
- The phone shell is adapted from Dimohod Trade's PhoneMockup3D: front/back faces, a 26 px metal perimeter built from narrow side rails, end caps and small corner facets (no stacked full-size planes), camera cutout and attached side buttons. Drag the body or surrounding field to rotate; swipe the screen to change captures. Use native pointer capture, keep the chosen angle after release, and reset it only with the reset control. Framer Motion springs smooth the rotation and swipe feedback. Separate zoom control avoids accidental popups during touch interaction. Keyboard arrows rotate the focused scene or change the focused screen; Home resets the scene. A nine-second Framer Motion cycle gently floats and rocks around the chosen angle, with a compact moving glass highlight and soft ground shadow. Pause/resume is explicit; no automatic slideshow. Reduced motion disables rotation and fades; vertical touch scrolling and pinch zoom remain native. The same solid shell appears on the project cover.

- Laptop: CSS 3D an intentionally asymmetric lid (85% width, shifted right) and wider base (96%), an angled resting pose, and closed gray chamfered corners. Larger responsive presentation (1080 px maximum, smaller mobile scene gutters), with thin exterior edges, a simple keyboard and trackpad, no stacked full-size planes or blur shadows. Default opening 155°, constrained to 60–165°; drag the top rim or use the labeled vertical native range input to the right of the model (higher means more open). Body drag rotates the laptop; display swipe switches screenshots. Keyboard arrows/Home, pause, reduced motion and native vertical scrolling match the phone. Framer Motion springs smooth manual rotation and hinge changes; gentle floating stops offscreen, in hidden tabs and during gestures. Reduced motion keeps manual hinge adjustment immediate and disables ambient motion.
