# Sunny Rentals: основания и изображения кейса

Кейс `/cases/sunny-rentals` описывает исходную систему собственного бизнеса аренды на Пхукете. История практического использования предоставлена владельцем в ТЗ. Мультипарковая версия Sunny Booking — отдельный проект. Из папок `new` ничего не публикуется. Количественные результаты, продажи и отзывы не выдумываются.

## Проверка исходного кода (только чтение)

| Возможность / технология | Основание в `/home/sunny-rentals` |
| --- | --- |
| React, TypeScript, Vite | корневые `package.json`, `vite.config.ts`, исходники `src` |
| FastAPI / Python | `backend/web_integration.py`, `backend/requirements.txt` |
| Telegram Mini Apps | `src/pages/AdminApp.tsx`, `window.Telegram.WebApp`, клиентские WebApp-компоненты |
| Telegram Bot API | `backend/telegram_bot.py`: `telebot.TeleBot`, WebAppInfo, отправка сообщений |
| Автопарк, владельцы, сезонные тарифы | `src/pages/CarsPage.tsx`, редакторы тарифов и характеристик, реальные снимки `old` |
| Месяц / Гант / фильтры | `src/pages/AdminScheduler.tsx`, `src/components/admin/MonthCalendarView.tsx`, `SchedulerCalendar.tsx` |
| Создание брони менеджером | `src/components/admin/BookingCreateForCRM.tsx`, `BookingFormDialog.tsx`, `createBookingFromCRM` |
| Статусы CRM, сообщения и AI-контроль | `src/pages/CRMPage.tsx`: start/pause/resume/stop, ручная отправка, карточки и заметки |
| AI-сервис | Anthropic SDK/API в `backend/web_integration.py`, `backend/telegram_bot.py`; `backend/claude_dialog.py` |

Pyrogram не указан: наличие установленного пакета в окружении не подтверждает его участие в показанном рабочем модуле. Автоматические follow-up не заявляются: надёжное подтверждение для исходного сценария не выделено. Next.js и архитектура мультипарковой платформы в стек исходного Sunny Rentals не переносятся. Сервисы, базы, клиентские хранилища, журналы переписок и внешние сайты не изменялись; тесты запускаются только в Marseloid.

В трёх CRM/AI-файлах персональные идентификаторы, контакты, заметки, параметры обращений и текст переписки закрыты непрозрачными масками до перекодирования. Это необратимое сокрытие в самом WebP, не CSS-оверлей: увеличение и скачивание открывают только обезличенный файл. Подписи явно отмечают сокрытие. Интерфейсы и данные не дорисовываются, имена не заменяются вымышленными. Снимок отдельной клиентской карточки и Telegram Desktop с посторонними чатами не публикуются.

Статистика, цены и отметки на скриншотах — состояние реального интерфейса, не показатели эффективности Marseloid и не тарифы разработки. В демонстрации четыре экрана для компьютера и четыре для телефона из шести тематических групп. У главной и каталога нет мобильной пары, у календаря и AI нет точного десктопного кадра — устройство не подменяется нерелевантным снимком. Модуль бронирования поясняет различие клиентского подтверждения и ручного создания брони.
